# Contributing

Thanks for considering contributing!

## Reporting bugs

- Include your Windows version, OBS version, and Advanced Scene Switcher version.
- Include UI and server logs (remove sensitive info if needed):
  - `%LOCALAPPDATA%\\ASS_Timer\\ASS_WS_Server.log`
  - UI log from the app window
- Describe expected vs. actual behavior.

## Development workflow

1. Fork the repo and create a feature branch.
2. Make changes with clear, focused commits.
3. Ensure the app still builds with PyInstaller.
4. Open a pull request with a short explanation.
