# Choose a License

You should add a license before publishing the repository.

Common choices:

- **MIT**: simple, permissive.
- **Apache-2.0**: permissive, includes explicit patent grant.
- **GPL-3.0**: copyleft (public redistribution must include source under GPL).

This folder includes templates:

- `LICENSE_MIT.txt`
- `LICENSE_APACHE-2.0.txt`
- `LICENSE_GPL-3.0.txt`

Pick one, copy it to the repository root as `LICENSE`, and edit the copyright line.
